**Confirmed by Gabriel 2026-09-16:** ORA pays for (1) a **CoStar Suite seat** (lease listings, lease comps, analytics/market history) and (2) a **LoopNet Silver listing plan** (advertising ORA's own vacancies — priority placement, CDX mail, per-listing view/lead analytics; NOT a data product).

**Why it matters:** [[ora-intelligence-platform-master-plan]] records a "no CoStar" constraint. That constraint is about the command-center app having no CoStar API/automated feed — it is NOT evidence ORA lacks CoStar access. Do not re-derive "ORA has no CoStar" from it.

**How to apply:**
- CoStar Suite data enters ORA systems only via **human-run exports** (saved search → Excel/CSV into an intake folder) or CoStar's own **saved-search alert emails**. CoStar/LoopNet terms of use prohibit robots/scrapers and automated extraction — never drive the Suite UI or LoopNet listing pages with browser automation to harvest data, even through Gabriel's logged-in Chrome.
- LoopNet Silver analytics (views/leads per ORA listing) are a legitimate demand signal for ORA's own asking rents.
- Consistent with [[procurement-stance-deepen-not-migrate]]: existing seats are used, not expanded.
