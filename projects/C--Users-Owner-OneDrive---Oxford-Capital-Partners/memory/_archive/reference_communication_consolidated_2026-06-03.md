# ORA Communication Patterns

## Brand Voice (all external)
- Professional, understated, institutional
- No superlatives — let the numbers speak
- Precise, authoritative, unhurried

## By Audience

### Tenants
- Professional, direct, respectful
- Reference specific lease provisions (section numbers)
- Include relevant dates, amounts, deadlines
- Delinquency escalation: reminder → formal notice → demand → legal referral (progressive tone)
- Renewals: lead with value proposition, present terms clearly, include response deadline
- Always specify the correct landlord entity for the property
- Formats: email body text AND .docx letter on ORA letterhead

### Brokers
- Collegial but efficient
- Lead with criteria match/mismatch
- Numbers-forward: SF, price, cap rate, $/SF before qualitative
